# Printer Monitor

Aplicação Django para monitorar o nível de toner e status de impressoras em rede.

> 🚧 Projeto em desenvolvimento. Este README será expandido conforme as funcionalidades forem implementadas.

## Sobre o projeto

O Printer Monitor permite:

- Cadastrar impressoras (número de série, IP, setor)
- Consultar o nível de toner remanescente de cada impressora
- Atualizar os dados manualmente ou automaticamente
- Receber notificação por e-mail quando o toner estiver acabando

Todos os dados de exemplo usados neste repositório (IPs, números de série, setores) são **fictícios**, gerados apenas para fins de demonstração.

## Tecnologias

- Python / Django
- PostgreSQL
- Docker e Docker Compose
